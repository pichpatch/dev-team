Security report

One report per release. A feature check uses the same columns as a checklist in the PR, with only the rows its diff touches (see the security standard's "Evidence and release decision"). Update it in place on every retest; do not copy it. It is complete when every row has a status, a repeatable "how tested", expected and actual results, and evidence (see the security standard's "When the report is complete"). State what was tested and what happened, with synthetic or redacted values only: never a secret, a token, or personal data.

Release or feature, and Issue(s)
To be supplied.
Revision tested
Commit or tag. Rows retested later name their own revision in the Evidence cell.
Environment and test accounts
Authorized environment, fixtures, and roles used. Never production credentials.
Depth
Patch, minor, or major, and any risk override with the reason.
Reviewer and model that ran
Role and the model that actually ran. State if the review was not cross-provider.

Result

Counts of PASS, FAIL, NOT APPLICABLE and NOT TESTED. Then one line: blocked (list the blocking rows) or not blocked. The human decides the release.

Checklist

One row per check, fixed when the review starts. For a release: the fixed checks (SECRET-FILES, AI-CRAWLERS for a public site, DEPENDENCIES, PROD-CONFIG), every SEC- requirement in the release, and each applicable OW- area with its ASVS/WSTG reference, and open follow-up from the feature checks. Status is PASS, FAIL, NOT APPLICABLE, or NOT TESTED.

ID Check: what must be true How tested: steps, tool, test data, environment Expected result Actual result Status Evidence: link, revision, round If FAIL: severity, blocking, owner, related paths

Not applicable and not tested

For each NOT APPLICABLE row, the scope inspected. For each NOT TESTED row, the blocker and the residual risk.

Follow-up, not blocking

Medium and Low findings, with severity, owner, and where they are tracked. They trigger no retest round.

Decisions for the human

Requirements Technical Lead did not follow with the remaining risk, findings still failing after the round limit, and anything that cannot be checked.
